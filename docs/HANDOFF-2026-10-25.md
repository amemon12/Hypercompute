# Handoff, 2026-10-25

Snapshot of the project at handoff on 2026-10-25. These changes are on GitHub `main`. The repository is private;
hypercompute.co is public. Use the dated cross-check report for subsequent verification.

## 1. Get the code

```bash
git clone https://github.com/amemon12/Hypercompute.git hypercompute
cd hypercompute
git log --oneline -1          # the commit that adds this file, or later
uv sync                       # Python 3.12, uv; the backend, join scripts, SDK, bench kit and demo app share this venv
```

Each folder under `integrations/` has its own project. Run `uv sync` inside the ones you test (fetch-agent, x402-proxy,
droid-autotune). For `integrations/convex-room`, run `npm ci`.

## 4. Machines and access

- GX10 (ASUS, GB10, 121 GiB unified memory) is the host. It is on a private home network with key-only SSH from the G14.
  Its checkout is at this commit, the host is running, no model is deployed, and the G14 and both Macs are joined.
  It has no screen; `docs/demo-app/TOPOLOGY.md` explains how the demo drives it.
- GX10 rules. Its sudo password belongs to the rental, so nobody types it. Never plan a disk tier (`gpu_disk`,
  `stream`) for a model bigger than its memory: that froze the box until a reboot, twice. `seed_and_run.py`
  refuses those tiers unless you pass `--allow-disk-tiers`, and the planner never pages from disk on a unified-memory
  host.
- Big models take minutes to load (the 671B took 391 s). Load them before the judges walk up.
